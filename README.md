# فروشگاه آسمان شب

پروژهٔ جنگو برای تبدیل قالب فروشگاه، ورود مدیر و پنل مدیریت به سایت دارای دیتابیس.

## اجرا

```powershell
$env:DJANGO_DEBUG = "1"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver --insecure
```

`DJANGO_DEBUG=1` فقط برای اجرای محلی است تا فایل‌های media ارائه شوند؛ `--insecure` نیز فایل‌های static مثل CSS را هنگام `DEBUG=False` سرو می‌کند. برای محیط واقعی، `DJANGO_DEBUG` را تنظیم نکنید و فایل‌های static و media را با وب‌سرور یا سرویس میزبانی ارائه کنید.

سایت: `http://127.0.0.1:8000/`  
داشبورد پنل: `http://127.0.0.1:8000/panel/`  
مدیریت محصولات: `http://127.0.0.1:8000/panel/products/`  
مدیریت سفارش‌ها: `http://127.0.0.1:8000/panel/orders/`  
مدیریت ادمین‌ها (فقط ادمین اصلی): `http://127.0.0.1:8000/panel/admins/`  
ثبت سفارش تلگرامی در پنل: از بخش سفارش‌ها، «ثبت سفارش تلگرامی» را انتخاب کنید.  
مدیریت دسته‌بندی‌ها و امکانات پیشرفته: `http://127.0.0.1:8000/django-admin/`

ورود پنل با همان کاربر superuser انجام می‌شود. بازدیدهای صفحهٔ اصلی در دیتابیس ثبت می‌شوند و نمودار پنل از زمان اجرای migration مربوط به بازدیدها داده جمع می‌کند.

ادمین اصلی از پنل حساب ادمین‌های فرعی را می‌سازد و می‌تواند آن‌ها را حذف کند؛ حذف حساب‌های ادمین اصلی ممکن نیست. هر ادمین می‌تواند رمز عبور خودش را از پنل تغییر دهد. در نمایش موبایل، گزینه‌های پنل از منوی همبرگری در دسترس هستند. برای سفارش‌های ثبت‌شده در تلگرام، اطلاعات مشتری و اقلام را در پنل وارد کنید و شمارهٔ سفارش ساخته‌شده و چهار رقم آخر تلفن را برای پیگیری به مشتری بدهید.

شناسهٔ مقصد سفارش تلگرام را ادمین اصلی از پنل، بخش «تنظیمات سایت» و گروه «فوتر و راه‌های ارتباطی» تغییر می‌دهد. نام کاربری تلگرام را با یا بدون `@` وارد کنید؛ این شناسه هم‌زمان برای سبد خرید، دکمهٔ سفارش صفحهٔ اصلی و لینک سفارش فوتر استفاده می‌شود.

فهرست محصولات صفحهٔ اصلی از مسیر `GET /api/products/` دریافت می‌شود. فایل‌های CSS، JavaScript، تصویر ماه و فونت‌های محلی در `static/store/` قرار دارند.

برای محصولاتی مانند تابلو می‌توان در فرم مدیریت چند سایز با قیمت جداگانه ثبت کرد؛ موجودی فعلاً بین سایزهای همان محصول مشترک است و تخفیف ثبت‌شده برای همهٔ سایزها اعمال می‌شود.

## نکتهٔ پیش از انتشار

`SECRET_KEY` و `DEBUG` را در `aseman_shab/settings.py` برای محیط واقعی تغییر دهید و `ALLOWED_HOSTS` را با دامنهٔ سایتتان پر کنید.
